# DiscordLink

Официальные загрузки DiscordLink для Windows 10/11 x64.

## Скачать программу

**[Setup и Portable — все выпуски](https://github.com/Kernefix/DiscordLink-Releases/releases)**

Текущий выпуск: **0.9.9.27**.

- [Скачать Setup](https://github.com/Kernefix/DiscordLink-Releases/releases/download/v0.9.9.27/DiscordLink_0.9.9.27_Setup.exe) — установка программы и ярлыков.
- [Скачать Portable ZIP](https://github.com/Kernefix/DiscordLink-Releases/releases/download/v0.9.9.27/DiscordLink_0.9.9.27.zip) — распакуйте всю папку и запустите `DiscordLink.exe`.
- [Контрольная информация Setup](https://github.com/Kernefix/DiscordLink-Releases/releases/download/v0.9.9.27/update-manifest.json).

Для скачивания не нужен доступ к приватному проекту или токен GitHub. .NET входит в комплект. При запуске EXE Windows запрашивает права администратора. Setup рассчитан на административную учётную запись, включая обычный UAC этой же учётной записи.

## Что нового в 0.9.9.27

- Setup и Portable можно скачать прямо в программе: с прогрессом, объёмом и отменой.
- Перед готовностью проверяются размер и SHA-256; для Setup также манифест того же выпуска GitHub.
- После проверки можно открыть папку. Установка и распаковка выполняются вручную; скачанные EXE программа не запускает.
- Карточка обновлений показывает время последней проверки. «Что нового» раскрывается отдельно.
- Отмена и полное удаление учитывают файлы загрузки и сохраняют постороннее содержимое.

В 0.9.9.26 остаются прежние ссылки проверки выпусков: переход на 0.9.9.27 выполняется через скачивание Setup или Portable. Встроенная загрузка доступна после установки новой версии.

## Что делает программа

DiscordLink управляет комплектным движком winws/WinDivert, предлагает три режима и Smart-подбор, диагностику сервисов Discord и отдельный UDP/STUN-тест. Движок Flowseal 1.10.4 поставляется вместе с программой и восстанавливается без скачивания.

Успешные сетевые проверки не подтверждают реальный голосовой звонок Discord. Фактический звонок проверяйте отдельно в своей сети. Программа не меняет DNS, системный hosts, прокси или правила файрвола.

## Удаление

Используйте «Система → Полностью удалить» либо штатное удаление Setup в параметрах Windows. Удаляется только принадлежащее программе содержимое; посторонние файлы и системный кэш значков не очищаются.
